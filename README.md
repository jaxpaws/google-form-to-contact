# google-form-to-contact
Google Apps Script to create a Google Contact from a Google Form submission.

## Form Structure
For reference, here are the questions in the form used with this Apps Script:


| Question Title            | Type | Additional Info |
|:--------------------------|:------------------|:-----------------------------------------------------------------------------------|
| First Name                | Short answer text |                                                                                    |
| Middle Name (optional)    | Short answer text |                                                                                    |
| Last Name                 | Short answer text |                                                                                    |
| Preferred Name (optional) | Short answer text |                                                                                    |
| Phone Number              | Short answer text | Validation: Regular expression - Matches - \\+?\\(?\d{3}\\)?[\s-]?\d{3}[\s-]?\d{4} |
| Phone Number Type         | Dropdown          | Options: home, work, mobile, other                                                 |
| Email Address             | Short answer text | Validation: Text - Email                                                           |
| Email Address Type        | Dropdown          | Options: home, work, other                                                         |
| Birth Month               | Dropdown          | Options: each month January-December                                               |
| Birth Day                 | Short answer text | Validation: Regular expression - Matches - ^([1-9]|[12][0-9]|3[01])$               |


## Steps to Implement
### 1. Create a Google Form
From Google Drive, select the *+ New* button then select *Google Forms* and choose *Blank Form*. Create any fields that you want to capture for your contact, including name, phone number, and email address.

See the Google People API documentation for the full list of fields to use to create a contact: https://developers.google.com/people/api/rest/v1/people#Person

### 2. Open Apps Script
From the form, select the 3 dots in the top right-hand corner to open form options and select *Apps Script*.

### 3. Create the Appropriate Files
Click the plus button to add a file named "Setup.gs". Copy the contents of Setup.gs in this repository and paste it into your newly created Setup.gs file.

There should already be a default Code.gs file in Apps Script, if not, add another file named "Code.gs". Now copy the contents of Code.gs in this repository and paste it into your Code.gs file.

### 4. Customize Code.gs
- Change the personData object properties to match your form question titles.
- Add or remove any properties from the Person object to match which fields are important for your created contacts.
- If you don't allow a selection of a full-text month, then you don't need to convert the month to a number for the Person object.

### 5. Install the trigger
Switch back to the Setup.gs file and select the setUp function as the function to run. Select the *Run* button to install the trigger on your form.

### 6. Test it
Publish your form and submit a test response. Go back to the Apps Script and navigate to the Executions page. Select the most recent execution to see any logs or errors generated by the script. If all looks good from the logs, then check your contacts to make sure the data was successfully added.
